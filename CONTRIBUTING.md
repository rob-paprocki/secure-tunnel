# Contributing

Thanks for taking a look. Each public repository here is a release copy. It changes only when a new version comes out, one commit per version, and development happens elsewhere, so a pull request can't be merged as it is.

If you found a bug or have an idea, open an issue (where the repository has issues turned on) and say what you ran, what you expected and what happened.

If you've already written a fix, open the pull request anyway. I'll bring the change across by hand, credit you in the changelog and close the pull request.

Security problems go through [SECURITY.md](SECURITY.md) instead.

A repository's own `CONTRIBUTING.md` wins over this file.
